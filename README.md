# Ghost — режим призрака для CS2 (`!ghost`)

Плагин для **Metamod:Source 2** (C++). Мёртвый игрок может бегать по карте призраком и при этом **никак не влиять на игру**.

> Основа — плагин Redie/Ghost от Pisex. Сигнатуры и раскладка структур взяты из [CS2Fixes](https://github.com/Source2ZE/CS2Fixes).

## Что умеет призрак

| Требование | Как сделано |
|---|---|
| Бегает и прыгает | Обычная пешка игрока после `Respawn()`. Пол и стены держат её как обычно. |
| Его нельзя зарезать, нож и пули проходят насквозь, он не закрывает союзников | У пешки обнуляется `m_nInteractsAs`. Трейсы ножа, пуль и гранат её не видят. Урон по призраку и от него дополнительно блокируется в `OnTakeDamagePre`. |
| Не трогает триггеры карты | Та же неосязаемость: триггеры не считают пешку игроком. |
| Невидим | `m_lifeState = LIFE_DYING` (клиенты считают его мёртвым), `EF_NODRAW`, `EF_NOSHADOW`, `kRenderNone`, прозрачность 0, тень 0. Перчатки и нож скинченджера не выдаются. |
| Не слышно | Хук `PostEventAbstract`: звуки пешки призрака (шаги, прыжки, приземление) получает только он сам. |
| Не нажимает E (двери, кнопки, подбор) | Детур `FindUseEntity`: для призрака игра не находит объект для E. Плюс детур `ProcessUsercmds` вырезает E, атаку, вторую атаку и перезарядку. |
| Не стреляет и не берёт оружие | Оружие снимается после спавна и раз в секунду. Подбор и покупка блокируются через `CanAcquire`. |
| Не влияет на раунд | Для игры он мёртвый (`LIFE_DYING`), поэтому не мешает концу раунда. Его `player_spawn` и `player_death` не отправляются клиентам: в килфиде пусто. |

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `!ghost`, `!redie` (`css_ghost`, `mm_ghost`) | мёртвый игрок T/CT | Войти в режим призрака. Повторный ввод — выйти. |
| `!unghost` (`css_unghost`, `mm_unghost`) | призрак | Выйти из режима: игрок снова мёртв. |
| `mm_ghost_toggle` | консоль сервера | Выключить или включить плагин. При выключении все призраки выходят из режима. |

Условия для `!ghost`: игрок мёртв, состоит в команде T или CT, раунд идёт (не во время заморозки и не после конца раунда), кулдаун прошёл.

Состояние сбрасывается при выходе игрока с сервера, смене команды, смерти, конце раунда и смене карты. После конца раунда пешка остаётся скрытой до следующего настоящего спавна: так у игрока не появляется лишняя смерть.

## Установка

1. Нужны Metamod:Source 2 и плагины Pisex: **Utils**, **Players** (оба через `IUtilsApi` / `IPlayersApi`) и **SkinChanger**. Без них плагин сам выгрузится.
2. Готовая сборка под Linux: [`release/ghost-linux-x86_64.zip`](release/ghost-linux-x86_64.zip). Распакуйте в `game/csgo/`:
   ```
   addons/ghost/ghost.so
   addons/metamod/ghost.vdf
   addons/configs/ghost.ini
   ```
3. Перезапустите сервер или выполните `meta load addons/ghost/ghost`.

## Конфиг `addons/configs/ghost.ini`

```
"Ghost"
{
    "model"     ""          // модель призрака, пусто = обычная
    "cooldown"  "5"         // кулдаун на !ghost, сек

    "sig_canacquire"       "..."   // подбор и покупка
    "sig_findusentity"     "..."   // E: двери, кнопки, подбор
    "sig_processusercmds"  "..."   // вырезание кнопок из команд игрока

    "usercmd_pb_offset"    "16"    // раскладка CUserCmd (CS2Fixes)
    "usercmd_size"         "0"     // 0 = посчитать автоматически
}
```

Сигнатуры взяты для Linux из [`gamedata/cs2fixes.jsonc`](https://github.com/Source2ZE/CS2Fixes/blob/main/gamedata/cs2fixes.jsonc). **После обновления CS2** берите свежие значения оттуда же (ключи `CCSPlayer_ItemServices_CanAcquire`, `FindUseEntity`, `ProcessUsercmds`). Если сигнатура не найдена, плагин пишет ошибку в лог и отключает только эту функцию, а не падает. Пустое значение тоже отключает функцию.

## Сборка из исходников

Требуются: clang, Python 3, [AMBuild](https://github.com/alliedmodders/ambuild), [hl2sdk ветки `cs2`](https://github.com/alliedmodders/hl2sdk/tree/cs2), [Metamod:Source](https://github.com/alliedmodders/metamod-source) с SourceHook (коммит до перехода на KHook, например `7ec0f16`).

```bash
# рядом лежат: hl2sdk-cs2/, metamod-source/, этот репозиторий
pip install ./ambuild
mkdir build && cd build
python3 ../Closed-eyes/ghost/configure.py \
    --hl2sdk-root .. \
    --mms_path ../metamod-source \
    --hl2sdk-manifests ../Closed-eyes/ghost/hl2sdk-manifests \
    --sdks cs2 --targets x86_64 --enable-optimize
ambuild
# результат: build/package/addons/...
```

Папка `SchemaEntity/` должна лежать рядом с `ghost/` (как в этом репозитории).

## Что проверено, а что нет

- ✅ Плагин **собирается** (clang 18, hl2sdk `cs2` от 30.09.2026, Metamod `7ec0f16`). Все внешние символы закрываются `libtier0.so`.
- ⚠️ **На живом сервере ещё не тестировался.** Перед боевым сервером проверьте на тестовом:
  1. нож (ЛКМ и ПКМ, спереди и сзади) по призраку — не попадает;
  2. нож, пули и HE по игроку, стоящему **за** призраком, — урон проходит;
  3. E на дверях, кнопках, оружии — ничего не происходит;
  4. у призрака нет оружия, его не видно и не слышно;
  5. последний живой умирает при призраках — раунд заканчивается;
  6. перезаход на тот же слот, смена команды, смена карты, `meta unload`.
- Если нож и пули всё ещё «съедаются» призраком, следующий шаг — детур `TraceShape` (сигнатура и пример фильтра есть в CS2Fixes).
- Номера виртуальных функций в `SchemaEntity` сверены с CS2Fixes: `StripPlayerWeapons` = 28 (Linux). `CollisionRulesChanged` вызывается через Utils API, поэтому от номера не зависит.
- События `player_spawn` и `player_death` призрака скрываются только от клиентов. Другие серверные плагины их по-прежнему видят.
