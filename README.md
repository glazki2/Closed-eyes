# Ghost — режим призрака для CS2 (`!ghost`)

Плагин для **Metamod:Source 2** на C++. Мёртвый игрок может бегать по карте призраком и при этом **никак не влиять на игру**.

**Готовая сборка для сервера (Linux):** [`release/ghost-linux-x86_64.zip`](release/ghost-linux-x86_64.zip)

Версия 3.0 — самостоятельный плагин: **не нужны** никакие другие плагины (Utils, Players, SkinChanger и т. п.), только Metamod:Source 2.0 актуальной версии (с KHook, API плагинов 18).

## Что умеет призрак

| Требование | Как сделано |
|---|---|
| Бегает и прыгает | Обычная пешка игрока после респавна. Пол и стены держат её как обычно. |
| Его нельзя зарезать, нож, пули и гранаты проходят насквозь, он не закрывает союзников | У пешки обнуляются слои взаимодействия (`m_nInteractsAs`): трейсы оружия и движения других игроков её не видят. Урон по призраку и от него блокируется (`CBaseEntity::TakeDamageOld`). |
| Невидим (модель, тень, радар) | `CheckTransmit`: пешка призрака вообще не отправляется другим игрокам. Плюс `EF_NODRAW`, `EF_NOSHADOW`, `kRenderNone`, прозрачность 0. |
| Не слышно | Пешку никто не получает, серверные звуки (`CMsgSosStartSoundEvent`) от неё не получает никто. Свои шаги клиент рисует сам, поэтому призраку отправляется `sv_footsteps 0` (только ему). |
| В таблице (TAB) мёртвый | У контроллера каждый тик ставится `m_bPawnIsAlive = false` и здоровье 0. |
| Не нажимает E (двери, кнопки, подбор, разминирование) | `FindUseEntity`: для призрака игра не находит объект для E. |
| Не активирует триггеры и кнопки карты | `CEntityIOOutput::FireOutputInternal`: выходы, где активатор — призрак, не срабатывают (`OnStartTouch`, `OnTrigger`, `OnPressed`…). |
| Не стреляет и не берёт оружие | Оружие снимается после спавна и каждые 0.5 с. Подбор и покупка блокируются (`CanAcquire`). |
| Не влияет на раунд и счёт | Когда в команде призрака не остаётся живых настоящих игроков, призраки этой команды тихо выходят из режима, и раунд заканчивается как обычно. В конце раунда все призраки тоже выходят. Их смерть не попадает в килфид, счёт и число смертей возвращаются. |
| Нет чёрного экрана | Пешка призрака остаётся «живой» (`LIFE_ALIVE`): любое другое состояние даёт чёрный экран. |
| Нет трупа при выходе | После выхода тело остаётся прозрачным и скрытым до следующего спавна. |

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `!ghost`, `!redie` (или `/ghost` — без сообщения в чате) | мёртвый игрок T/CT | Войти в режим призрака. Повторный ввод — выйти. |
| `!unghost` | призрак | Выйти из режима: игрок снова мёртв. |
| `css_ghost`, `css_unghost` (консоль игрока) | игрок | То же самое из консоли. |
| `mm_ghost_toggle` | консоль сервера | Выключить или включить плагин. При выключении все призраки выходят из режима. |
| `mm_ghost_status` | консоль сервера | Показать состояние плагина и число призраков. |

Условия для `!ghost`: игрок мёртв, состоит в команде T или CT, не разминка, кулдаун прошёл. На каждый отказ игрок получает сообщение в чат.

## Когда призрак перестаёт быть призраком

| Событие | Что происходит |
|---|---|
| `!unghost` или повторный `!ghost` | Тихая смерть: без килфида, счёт и смерти возвращаются. |
| Конец раунда | Тихая смерть. |
| В команде не осталось живых настоящих игроков | Тихая смерть, раунд заканчивается. |
| Смена команды (в т.ч. в наблюдатели) | Тихая смерть: без килфида, счёт не меняется. Срабатывает и по событию, и по проверке команды каждый тик. |
| Респавн игрока другим плагином или игрой | Игрок становится обычным живым: видимым, уязвимым, с нормальной коллизией. |
| Выход с сервера, смена карты | Состояние слота сбрасывается. |
| `meta unload ghost` | Все призраки выходят из режима, все пешки восстанавливаются, все хуки снимаются. |

## Установка

1. Нужен **Metamod:Source 2.0 актуальной сборки** (с KHook). Плагины под старый Metamod с SourceHook новый Metamod не загружает, и наоборот.
2. **Удалите старую версию**, если ставили: `addons/ghost/ghost.so`, `addons/configs/ghost.ini`.
3. Распакуйте [`release/ghost-linux-x86_64.zip`](release/ghost-linux-x86_64.zip) в `game/csgo/`:
   ```
   addons/ghost/bin/linuxsteamrt64/ghost.so
   addons/ghost/ghost.ini
   addons/metamod/ghost.vdf
   ```
4. Перезапустите сервер или выполните `meta load addons/ghost/bin/linuxsteamrt64/ghost`.
5. `meta list` должен показать `Ghost (3.4.0) by glazki2`. В консоли при загрузке будет `[Ghost] loaded`. Если какая-то сигнатура не найдена, будет строка `[Ghost] ... signature not found` — отключится только эта функция.

## Диагностика

В консоли сервера на каждую команду пишется `[Ghost] !ghost from slot N`, а при первом событии игры — `[Ghost] FireEvent hook works`. Если после `!ghost` в консоли ничего нет — чат-хук не сработал; пришлите вывод `meta list` и `mm_ghost_status`.

## Если в `meta list` плагин показан как `<ERROR>`

Выполните `meta info <номер>` или посмотрите строку загрузки плагина в начале лога.

- `Plugin uses old SourceHook Metamod build (17 < 18)` — у вас старая сборка плагина. Возьмите текущую из `release/`.
- `Plugin requires newer Metamod version` — обновите Metamod.
- `version 'GLIBC_2.3x' not found` — сборка не под Steam Runtime. Сборка из `release/` требует не больше GLIBC 2.14.
- `CGameEventManager vtable not found` — сервер другой версии, чем ожидалось; пришлите лог.

## Сборка из исходников

```bash
./build.sh            # скачает зависимости и соберёт build/ghost-linux-x86_64.zip
```

Нужны git, python3, pip, clang, lld, curl, dpkg-deb, zip и binutils. Версии зависимостей закреплены в `build.sh`: hl2sdk `cs2` @ `22087f5`, Metamod:Source @ `05c5c63` (KHook, API 18).

CS2 работает в Steam Runtime «sniper» с **glibc 2.31**, поэтому `build.sh` собирает clang'ом с sysroot из пакетов Ubuntu 20.04 (glibc 2.31, libstdc++ линкуется статически) и в конце проверяет, что `ghost.so` не требует glibc новее 2.31.

## Что проверено, а что нет

- ✅ **Собирается** без ошибок под актуальный Metamod:Source 2.0 (KHook).
- ✅ `ghost.so` загружается через `dlopen(RTLD_NOW)` **под glibc 2.31**, `CreateInterface("ISmmPlugin")` отдаёт объект плагина, `GetApiVersion()` = **18** — новый Metamod его примет.
- ✅ Не зависит от других плагинов Metamod.
- ⚠️ **Номера функций и сигнатуры не сверены с настоящим `libserver.so`** в среде сборки. Если какая-то не найдена, это будет в консоли сервера при загрузке.
- ⚠️ **На живом сервере ещё не тестировался.** Проверьте на тестовом:
  1. нож (ЛКМ и ПКМ, спереди и сзади) по призраку — не попадает;
  2. нож, пули и HE по игроку **за** призраком — урон проходит;
  3. E на дверях, кнопках, оружии, C4 — ничего не происходит;
  4. триггеры и кнопки карты не срабатывают от призрака;
  5. призрака не видно и не слышно, у него нет оружия, нет чёрного экрана;
  6. последний живой умирает при призраках — раунд заканчивается;
  7. выход из режима — нет трупа и записи в килфиде, счёт не меняется;
  8. перезаход на тот же слот, смена команды, смена карты, `meta unload ghost`.
