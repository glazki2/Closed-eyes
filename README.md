# Ghost — режим призрака для CS2 (`!ghost`)

Плагин для **Metamod:Source 2** на C++. Мёртвый игрок может бегать по карте призраком и при этом **никак не влиять на игру**.

**Готовая сборка для сервера (Linux x86_64):** [`release/ghost-linux-x86_64.zip`](release/ghost-linux-x86_64.zip)

## Что умеет призрак

| Требование | Как сделано |
|---|---|
| Бегает и прыгает | Обычная пешка игрока после `Respawn()`. Пол и стены держат её как обычно. |
| Его нельзя зарезать, нож, пули и гранаты проходят насквозь, он не закрывает союзников | У пешки обнуляется `m_nInteractsAs`. Трейсы оружия и движения других игроков её не видят. Урон по призраку и от него дополнительно блокируется. |
| Невидим (модель, тень, радар) | **`CheckTransmit`**: пешка призрака вообще не отправляется другим игрокам (как `!hide` в CS2Fixes и в redie от exkludera). Плюс `EF_NODRAW`, `EF_NOSHADOW`, `kRenderNone`, прозрачность 0 и `LIFE_DYING`. |
| Не слышно | Пешку никто не получает, а звуки (`CMsgSosStartSoundEvent`) от неё дополнительно получает только сам призрак. |
| Не нажимает E (двери, кнопки, подбор, разминирование) | Детур `FindUseEntity` (из CS2Fixes): для призрака игра не находит объект для E. |
| Не активирует триггеры и кнопки карты | Детур `CEntityIOOutput::FireOutputInternal` (из CS2Fixes): выходы, где активатор — призрак, не срабатывают (`OnStartTouch`, `OnTrigger`, `OnPressed`…). |
| Не стреляет и не берёт оружие | Оружие снимается после спавна и каждые 0.5 с. Подбор и покупка блокируются через `CanAcquire`. |
| Не влияет на раунд и счёт | Для игры он мёртвый (`LIFE_DYING`): не мешает концу раунда, боты его не видят. Его смерть не попадает в килфид, а счёт и число смертей после выхода из режима возвращаются. |
| Нет чёрного экрана | `LIFE_DYING` ставится через 0.25 с после возрождения: если поставить сразу, у игрока будет чёрный экран (так сделано в redie от exkludera). |
| Нет трупа при выходе | После выхода тело остаётся прозрачным и скрытым до следующего спавна. |

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `!ghost`, `!redie` (`css_ghost`, `mm_ghost`) | мёртвый игрок T/CT | Войти в режим призрака. Повторный ввод — выйти. |
| `!unghost` (`css_unghost`, `mm_unghost`) | призрак | Выйти из режима: игрок снова мёртв. |
| `mm_ghost_toggle` | консоль сервера | Выключить или включить плагин. При выключении все призраки выходят из режима. |

Условия для `!ghost`: игрок мёртв, состоит в команде T или CT, раунд идёт, не разминка, кулдаун прошёл. На каждый отказ игрок получает сообщение в чат.

## Когда призрак перестаёт быть призраком

| Событие | Что происходит |
|---|---|
| `!unghost` или повторный `!ghost` | Тихая смерть: без килфида, счёт и смерти возвращаются. |
| Конец раунда | Логика призрака выключается без смерти. Тело остаётся скрытым до респавна в новом раунде, потом всё восстанавливается. |
| Смена команды | Тихая смерть. |
| Респавн игрока другим плагином или игрой | Игрок становится обычным живым: видимым, уязвимым, с нормальной коллизией. |
| Выход с сервера, смена карты | Состояние слота сбрасывается. |
| `meta unload ghost` | Все призраки выходят из режима, все пешки восстанавливаются, все хуки снимаются. |

После восстановления у игрока всегда возвращаются нормальные слои коллизии. Если сохранённого значения нет, оно берётся у любого живого игрока, чтобы никто не остался неуязвимым.

## Установка

1. Нужны Metamod:Source 2 и плагины Pisex **Utils** и **Players**. **SkinChanger** не обязателен: без него просто не блокируются скины перчаток и ножа.
2. Распакуйте [`release/ghost-linux-x86_64.zip`](release/ghost-linux-x86_64.zip) в `game/csgo/`:
   ```
   addons/ghost/ghost.so
   addons/metamod/ghost.vdf
   addons/configs/ghost.ini
   ```
3. Перезапустите сервер или выполните `meta load addons/ghost/ghost`.
4. Проверьте `meta list` и консоль: если какая-то сигнатура не найдена, плагин напишет об этом в лог и выключит только эту функцию.

## Конфиг `addons/configs/ghost.ini`

| Ключ | По умолчанию | Назначение |
|---|---|---|
| `model` | пусто | Модель призрака. Пусто — обычная. |
| `cooldown` | `5` | Кулдаун на `!ghost` в секундах. |
| `sig_canacquire` | из CS2Fixes | Подбор и покупка. |
| `sig_findusentity` | из CS2Fixes | E на дверях, кнопках, оружии. |
| `sig_fireoutput` | из CS2Fixes | Триггеры и кнопки, активированные призраком. |
| `sig_processusercmds` | пусто (выключено) | Запасное вырезание кнопок из команд игрока. Включайте, только если `FindUseEntity` не найден. |
| `usercmd_pb_offset`, `usercmd_size` | `16`, `0` | Раскладка `CUserCmd` для `ProcessUsercmds` (из CS2Fixes). |

**После обновления CS2** берите свежие сигнатуры из [`gamedata/cs2fixes.jsonc`](https://github.com/Source2ZE/CS2Fixes/blob/main/gamedata/cs2fixes.jsonc) (ключи `CCSPlayer_ItemServices_CanAcquire`, `FindUseEntity`, `CEntityIOOutput_FireOutputInternal`, `ProcessUsercmds`). Пустое значение выключает функцию.

## Сборка из исходников

```bash
./build.sh            # скачает hl2sdk-cs2, Metamod, AMBuild и соберёт build/ghost-linux-x86_64.zip
```

Нужны git, python3, pip, clang и zip. Версии зависимостей закреплены в `build.sh`: hl2sdk `cs2` @ `22087f5`, Metamod @ `7ec0f16` (последний коммит с SourceHook).

## Что проверено, а что нет

- ✅ **Собирается** без ошибок (clang 18, `-Wall -Werror`) с текущим hl2sdk-cs2.
- ✅ Все внешние символы `ghost.so` закрываются `libtier0.so` движка.
- ✅ `ghost.so` загружается через `dlopen(RTLD_NOW)`, и `CreateInterface("ISmmPlugin")` отдаёт объект плагина, то есть Metamod его увидит.
- ⚠️ **Сигнатуры не сверены с настоящим `libserver.so`**: в среде сборки Steam был недоступен. Они взяты из актуального CS2Fixes. Если какая-то не найдена, это будет в логе сервера.
- ⚠️ **На живом сервере ещё не тестировался.** Перед боевым сервером проверьте на тестовом:
  1. нож (ЛКМ и ПКМ, спереди и сзади) по призраку — не попадает;
  2. нож, пули и HE по игроку **за** призраком — урон проходит;
  3. E на дверях, кнопках, оружии, C4 — ничего не происходит;
  4. триггеры и кнопки карты не срабатывают от призрака;
  5. призрака не видно и не слышно, у него нет оружия, нет чёрного экрана;
  6. последний живой умирает при призраках — раунд заканчивается;
  7. выход из режима — нет трупа и записи в килфиде, счёт не меняется;
  8. перезаход на тот же слот, смена команды, смена карты, `meta unload ghost`.
- Если нож и пули всё ещё упираются в призрака, следующий шаг — детур `TraceShape` (сигнатура и пример фильтра есть в CS2Fixes).
- Событие `player_death` призрака скрывается только от игроков. Другие серверные плагины его видят.

## Источники

- [CS2Fixes](https://github.com/Source2ZE/CS2Fixes): `CheckTransmit` и раскладка `CCheckTransmitInfo`, детуры `FindUseEntity`, `FireOutputInternal`, `ProcessUsercmds`, `CanAcquire`, сигнатуры, номера виртуальных функций.
- [exkludera-cssharp/redie](https://github.com/exkludera-cssharp/redie): задержка `LIFE_DYING` против чёрного экрана, прозрачная пешка против трупа, `DontBroadcast` для смерти, блокировка выходов сущностей.
- [DynLibUtils](https://github.com/komashchenko/DynLibUtils): поиск сигнатур (`SchemaEntity/module.cpp`).
- Исходный плагин Ghost/Redie от Pisex.
